# ⚡ NEON AURA AR

### Bring Superpowers to Your Hands!

**NEON AURA AR** is an interactive, webcam-based hand-tracking experience that transforms your hand movements into dynamic neon visual effects and superpower animations.

Built using JavaScript, HTML, CSS, and MediaPipe Hands, this project explores real-time computer vision, gesture recognition, creative coding, and interactive visual experiences — all without requiring any physical controllers.

🌐 **Live Demo:** [Try NEON AURA AR](https://kritthik.github.io/Neon-Aura-AR/)

💻 **GitHub Repository:** [Neon-Aura-AR](https://github.com/kritthik/Neon-Aura-AR)

---

## ✨ Features

- **Real-Time Hand Tracking:** Detects and tracks up to two hands using MediaPipe Hands.
- **Gesture Recognition:** Recognizes hand gestures such as pinching, open hands, and fists.
- **8 Interactive Superpowers:** Activate different visual effects using a finger-snap gesture.
- **Dynamic Visual Themes:** Choose from five different visual themes.
- **Neon Particle Effects:** Animated particles, glowing trails, shockwaves, and visual effects.
- **Interactive HUD:** Displays live hand detection, FPS, gesture, spread percentage, and active superpower.
- **Audio Effects:** Dynamic sound effects and audio feedback based on hand interactions.
- **Two-Hand Interactions:** Creates connecting energy lines, lightning effects, and geometric patterns between both hands.

## 🚀 Getting Started

### Prerequisites

- A laptop or desktop with a webcam
- A modern web browser (Google Chrome recommended)
- An internet connection to load MediaPipe libraries from the CDN

### Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/kritthik/Neon-Aura-AR.git
```

**2. Navigate to the project directory**

```bash
cd Neon-Aura-AR
```

**3. Launch the application**

Open `index.html` using a local development server.

For example, if you have VS Code, you can use the Live Server extension.

**4. Start the experience**

- Open the application in your browser.
- Allow webcam access when prompted.
- Click **Enter Experience**.
- Show your hands to the camera.
- Experiment with different gestures and superpowers!

> Note: Camera access requires a secure context, such as HTTPS or localhost. GitHub Pages already provides HTTPS.
